LESSON 01 · BEGINNER

HTML Basics

Learn how a webpage gets its structure.

What is HTML?

HTML stands for HyperText Markup Language. It defines the structure and content of a webpage.

Think of a website as a house: HTML creates the structure, CSS decorates it, and JavaScript adds interactive behaviour.

Your first HTML document

<!DOCTYPE html> <html lang="en"> <head> <title>My First Website</title> </head> <body> <h1>Hello World!</h1> <p>Welcome to HTML.</p> </body> </html>

Understand each part

<!DOCTYPE html> tells the browser to use modern HTML.

<head> contains page information, such as the title.

<body> contains the webpage content users see.

<h1> creates a main heading.

<p> creates a paragraph.

Hello World!

Welcome to HTML.

Remember: most HTML elements have an opening tag, content and a closing tag. Some elements, such as img and br, do not need a closing tag.

HTML Elements

Learn how to add useful content to your webpage.

1. Links

The anchor element creates a clickable link.

<a href="https://example.com">Visit Website</a>

2. Images

The img element displays an image. The alt attribute provides alternative text describing the image.

<img src="flower.jpg" alt="A beautiful flower">
Keep your image file in the correct folder, or use a valid image URL. Always provide meaningful alt text.

3. Lists

Use ul for an unordered list and ol for a numbered list.

Semantic elements describe the purpose of their content. Examples include header, nav, main, section, article and footer.

LESSON 03 · BEGINNER

CSS Basics

Transform plain HTML into an attractive webpage.

What is CSS?

CSS stands for Cascading Style Sheets. It controls the appearance, spacing, colors and layout of HTML elements.

CSS syntax

h1 { color: purple; font-size: 32px; }

Selector: h1 selects the heading.

Property: color is the style you want to change.

Value: purple is the value assigned to color.

Important CSS properties

color: changes text color.

background-color: changes the background color.

font-size: changes text size.

margin: creates space outside an element's border.

padding: creates space inside an element's border.

border-radius: rounds the corners of an element.

Class selectors

A class lets you apply the same style to multiple elements.

.my-card { background-color: #f0eaff; padding: 20px; border-radius: 12px; }

In HTML, use class="my-card" on an element to apply the style. The dot in .my-card identifies a CSS class selector.

LESSON 04 · BEGINNER+

The CSS Box Model

Understand how browsers calculate space around elements.

Four parts of the Box Model

Content: the text or image inside the element.

Padding: space between content and border.

Border: the line surrounding padding and content.

Margin: space outside the border.

Margin = outside space

Why use box-sizing: border-box?

* { box-sizing: border-box; }

This makes the declared width include the content, padding and border, which makes many layouts easier to manage.

LESSON 05 · INTERMEDIATE

Flexbox & Grid

Learn how to organize elements into modern layouts.

Flexbox

Flexbox is useful for arranging items in a row or column.

.container { display: flex; justify-content: center; align-items: center; gap: 15px; }

justify-content aligns items along the main axis. align-items aligns items along the cross axis.

CSS Grid

Grid is useful for two-dimensional rows and columns.

.cards { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; }

Here, repeat(3, 1fr) creates three equal-width columns.

When to use which?

Flexbox: navigation bars, button groups and single-direction layouts.

Grid: card collections, galleries and row-and-column layouts.

LESSON 06 · INTERMEDIATE

Responsive Design

Make your website adapt to mobile, tablet and desktop screens.

What is responsive design?

Responsive design allows a website to adapt its layout to different screen sizes instead of requiring a separate page for each device.

Media queries

.cards { display: grid; grid-template-columns: repeat(3, 1fr); } @media (max-width: 600px) { .cards { grid-template-columns: 1fr; } }

On larger screens, this example creates three columns. When the viewport is 600px wide or less, it changes to a single column.

More responsive design tips

• Add the viewport meta tag in your HTML head.

• Use flexible widths and CSS Grid or Flexbox.

• Avoid fixed widths that make content overflow.

• Test the page at different screen sizes.
